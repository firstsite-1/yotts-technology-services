# Tsige Technology Services

## Project Overview
This project documents the development and deployment of the Tsige Technology Services (TTS) website.
The website was built to present computer and technology services for small businesses while developing hands-on skills in HTML, CSS, Git, GitHub, web deployment, and domain configuration.

## Technologies Used
- HTML5, CSS3
- Git, GitHub
- GitHub Pages
- DNS configuration, HTTPS

## Website Development
- Built the website structure and content using HTML5.
- Styled the website layout, colors, navigation, and visual elements using CSS3.
- Created navigation and content sections for services, company information, projects, and contact information.
- Used Git and GitHub to track changes and maintain the website project.

## Deployment and Domain Configuration
- Deployed the website using GitHub Pages.
- Configured a custom domain for the website.
- Configured DNS A records and a CNAME record to connect the custom domain to GitHub Pages.
- Enabled HTTPS to provide a secure connection to the website.

## Troubleshooting
- Troubleshot and corrected website layout and styling issues during development.
- Resolved logo sizing and file-path issues to ensure the website displayed correctly.
- Resolved DNS configuration issues while connecting the custom domain to GitHub Pages.

## Skills Demonstrated
- HTML5 and CSS3 web development
- Git and GitHub version control
- GitHub Pages website deployment
- DNS and custom domain configuration
- HTTPS configuration
- Website troubleshooting and problem solving
